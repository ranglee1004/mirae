# 미래에셋 운영 통합 대시보드

## 실행 방법
1. 압축을 해제합니다.
2. `index.html`을 더블클릭해 브라우저에서 엽니다.
3. 별도 설치나 서버 없이 동작합니다.

## 반응형 기준
- 데스크톱: 1367px 이상
- 태블릿: 721px ~ 1366px
- 모바일: 720px 이하

## 주요 구현 사항
- 순수 HTML / CSS / JavaScript
- 아이콘 전용 92px 사이드바
- 선택 메뉴 활성화 스타일
- 마우스 Hover/키보드 Focus 시 우측 툴팁 표시
- 1:1 프로필 아바타와 도넛 차트
- 외부 라이브러리 및 인터넷 연결 불필요
